# `> FASTMCP TOOL SECURITY`

Tools exposed to the LLM are strictly sandboxed and classified by risk levels:

```text
+-----------------------------------------------------------------------+
|                           FastMCP TOOL REGISTRY                        |
+-----------------------------------------------------------------------+
  │
  ├── [LOW RISK] (Auto-Executed, Read-Only)
  │     ├── get_weather(location)
  │     ├── search_public_knowledge(query)
  │     └── convert_currency(amount, from, to)
  │
  ├── [MEDIUM RISK] (Tenant-Isolated, Audit Logged)
  │     ├── query_user_documents(tenant_id, query)
  │     ├── search_nearby_places(lat, lng, category)
  │     └── fetch_user_telemetry(user_id)
  │
  └── [HIGH RISK] (Requires Explicit User Confirmation Modal)
        ├── initiate_payment(plan_id, amount)
        ├── delete_user_memory(user_id, memory_id)
        └── execute_database_mutation(sql_command)
```

# `> TECHNICAL DEEP DIVES`

<details>
<summary><b>👁️ 1. PyTorch 3D-CNN Spatio-Temporal Video Pipeline</b></summary>

```text
  Input Tensor: (B, C, T, H, W) -> [Batch, 3 Channels, 16 Frames, 112, 112]
        │
        ▼
   [ 3D Convolution 1 ]  -->  nn.Conv3d(3, 64, kernel_size=(3, 3, 3))
        │
   [ MaxPool3d (1,2,2) ]  -->  Preserves temporal frame depth, scales spatial dimensions
        │
   [ 3D Convolution 2 ]  -->  nn.Conv3d(64, 128, kernel_size=(3, 3, 3))
        │
   [ MaxPool3d (2,2,2) ]  -->  Downsamples spatial + temporal feature maps
        │
   [ Fully Connected ]   -->  Linear classifier -> Gesture Label & Confidence %
```
</details>

<details>
<summary><b>⚡ 2. LangGraph Stateful Agentic Graph Router</b></summary>

```text
  [START] ──> (Input Guard Check) ──> { Is Injection? }
                                            │ No
                                            ▼
                                  (Language Detector)
                                            │
                                            ▼
                                 (Intent Classifier)
                                  /        |        \
                             [RAG]     [Vision]   [MCP Tool]
                                  \        |        /
                                   (State Checkpoint)
                                            │
                                            ▼
                                   (Output Guard Filter) ──> [END]
```
</details>

<details>
<summary><b>🛡️ 3. Defense-in-Depth 15 Security Layers</b></summary>

1. **Network Layer:** Cloudflare WAF, TLS 1.3 encryption, IP throttling.
2. **API Layer:** JWT authorization, OAuth2 PKCE flow, FastAPI Pydantic input sanitization.
3. **Identity Layer:** Spring Security RBAC with roles (`User`, `Student`, `Pro`, `Admin`, `SuperAdmin`).
4. **LLM Input Guard:** Regex + DeBERTa checking for prompt injection, jailbreaks, system prompt leakage.
5. **RAG Isolation:** Strict metadata filtering (`tenant_id == current_user.tenant_id`) enforced at vector database query time.
6. **MCP Tool Guard:** Schema validation, rate-limiting per tool, token bucket isolation.
7. **Payment Guard:** HMAC-SHA256 signature verification on backend webhooks.
8. **Output Guard:** PII redact masking (credit cards, passwords, SSNs) before streaming to Flutter client.
</details>

<details>
<summary><b>💻 4. Core CS & OS Kernel Integration</b></summary>

* **OS Multiprocessing:** `asyncio` GIL-bypassing worker pools for CPU-bound 3D-CNN matrix operations.
* **Computer Networks OSI:** Layer 7 (WSS / HTTP/2), Layer 6 (TLS 1.3), Layer 4 (UDP audio frame streaming).
* **MLOps Pipelines:** Automated MLflow tracking, DVC dataset versioning, and Evidently AI drift detection.
</details>

# `> QUICK START`

### 1. Launch Local Infrastructure Stack
```bash
docker-compose up -d postgres redis qdrant mlflow
```

### 2. Run AI Backend Engine (FastAPI)
```bash
cd backend/fastapi
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### 3. Run Enterprise Business Microservice (Spring Boot)
```bash
cd backend/springboot
./mvnw spring-boot:run
```

### 4. Run Flutter 3D App
```bash
cd mobile/flutter_app
flutter pub get
flutter run -d chrome  # Or Windows / Android / iOS
```
